This service works by allowing Atenean students to register as either a tutor or as a tutee. As a tutor, students are able to list courses and subjects they are able to teach and post tutoring sessions for a certain course or subject at a given time and location and are able to set a maximum number of students that are able to participate in that given session. As a tutee, students are able to sign up for a slot for these same sessions and are able to cancel a booking they have made provided that they cancel it a day before the session. Tutoring sessions hosted by Ateneo and other organizations are also posted in this service with students being able to sign up for these sessions.
